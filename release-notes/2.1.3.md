# 2.1.3 — Android Digest handoff

- Add an Android-only **Save to Supernote Digest** action for selected Reader text. Supernote Bridge presents the excerpt and source for user confirmation before saving.
- Keep ordinary Markdown provenance independent of Transcripts. Managed transcript selections require the v1 `selectionProvenance` capability and matching local mirror page identities.
- Validate bounded payloads, use deterministic request IDs, persist only per-vault request statuses locally, reject stale selections, and accept only matching Bridge callbacks. Reopening a saved request checks the same Bridge receipt without creating another Digest.
- Preserve existing quote-to-Obsidian behavior, optional page chips, Sidebar hooks, and standalone Reader fallback.
- Use Bridge's **Open original notebook** action with the source provenance. Native Notes' Digest source action requires an embedded `.note` reference, which Reader and Bridge do not write; native Digest-to-notebook navigation is unsupported.
- Document the Android workflow, helper and provider compatibility boundaries.

No settings, reading positions, excerpts, or `data.json` are included. Upstream MIT attribution remains. Controlled provider creation/readback/native visibility were verified against Knowledge 1.00.147. Reader-to-Bridge confirmation and Cancel passed on Nomad for ordinary Markdown and a managed transcript. The complete production Save/acknowledgement/Open-original sequence remains unverified. No `.note` files were modified; native cloud/Partner sync, rename behavior, and cross-device resolution were not verified.

This release note does not imply a public release or installation. Source/browser verification and device behavior are separate evidence.
