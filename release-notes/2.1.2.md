# 2.1.2 — independent reader and optional integrations

- Keep this repository as the single maintained reader source. Downstream distributions can pin its version and file hashes instead of applying their own upstream patches.
- Accept the version 1 Transcripts page-link adapter, retaining compatibility with the older unversioned adapter. Missing, disabled, unsupported or failing adapters use normal Markdown rendering; incomplete adapter output is cleared first.
- Preserve the existing Paper reader gestures, position/heading handling, menu and font readiness behavior. Paper is optional; base styles for reader-owned gesture controls now ship with the reader.
- Guard optional Sidebar hooks and preserve ordinary reader/editor navigation when a companion is absent or fails.
- Preserve the `md-reader` plugin ID and existing settings/reading-position format. Upstream MD Reader and this fork remain alternative installations under that ID.

No saved settings, personal reading positions or `data.json` are included. Upstream MIT attribution remains. Native Digest capture is still deferred.

This is a source-tested release candidate. No release tag or device installation is implied; installed-device verification remains separate.
